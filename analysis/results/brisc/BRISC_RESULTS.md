# External validation on BRISC 2025

Session A. Generated by `analysis/external_validation_brisc.py metrics`.

## Read this first

**BRISC 2025 is not an external dataset for these models. Most of it is the training set.**

- 4802 of 6,000 BRISC images (80.0%) are near-duplicates of images in `data/brain_tumor/`.
- 3366 of 6,000 (56.1%) match the internal **training** split specifically.
- A pixel check on 40 random distance-0 pairs gave mean absolute difference 0.0 and correlation 1.0 on all 40. They are the same image files under new names. Evidence figure: `overlap_evidence_pairs.png`.

The contamination is not spread evenly. It sits almost entirely in the tumour classes:

| BRISC class | images | match internal train | genuinely unseen |
|---|---|---|---|
| glioma | 1401 | 965 (69%) | 436 |
| meningioma | 1635 | 1134 (69%) | 501 |
| pituitary | 1757 | 1218 (69%) | 539 |
| notumor | 1207 | 49 (4%) | 1158 |

So on the full BRISC set the model is largely being re-shown tumours it memorised, while the no-tumour class is a real test. That combination flatters the tumour miss rate specifically, which is the number that matters most.

**Everything below is reported on the clean subset: n = 2634, the BRISC images whose nearest internal training image is more than perceptual-hash Hamming distance 5 away.** Full-BRISC numbers appear only in the contamination-effect table, labelled as such.

One limitation the clean subset does not fix: neither dataset ships patient identifiers, so other slices from the same patients may still be in training. **The clean subset is an upper bound on true external performance, not an unbiased estimate.**

## 9. Method and provenance

- MC Dropout, T = 20, matching training.
- Inference only, `torch.no_grad()` throughout. No optimizer, no backward pass, nothing fitted on BRISC.
- Preprocessing asserted identical to `get_transforms("test")` in `src/code.py`: resize to 224x224, ImageNet normalisation.
- MC path verified bit-identical to `predict_with_uncertainty` on every checkpoint before any cache was written.
- Bootstrap percentile CIs, 1000 resamples.
- Entropy in nats. `results/20260703_155524/` reports entropy in bits; the caches carry `entropy_bits` for that comparison.
- Checkpoints: `results/20260703_155524/{vit,resnet50}/seed_{42,123,7,2024,31}/`.
