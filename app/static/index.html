  • DICOM is read straight from the scanner. The app windows it using the setting stored in the file, and says on the result how the picture was made. Accuracy figures for this tool were measured on slices exported as JPEG, so treat a DICOM result with more caution and check the picture looks right.
  • One slice, not a whole study. This tool judges a single image. It does not combine slices into one answer.

      Run this on your own laptop

      This page, running on your machine, offline. Same model, same settings, same answers.

      Windows

      1 Download and install

      2 Double-click the downloaded file. That is everything.

      It downloads the app, installs it, puts a shortcut on your desktop and opens it. A few minutes, mostly waiting for the download. After that it never needs the internet again.

      Windows may warn that the file is from an unknown publisher, because it is not code-signed. Choose More info then Run anyway, or ask whoever sent you the link.

      Windows, without the installer

      The same application as a plain zip, if you would rather unpack it yourself or put it straight onto a USB stick.

      1 Download the zip

      2 Right-click it and choose Extract All

      3 Open the folder and double-click BrainMRITriage.exe

      Other ways: Mac, Linux, or if you already have Python

      This route needs Python 3.10 or newer. It downloads one small file that fetches everything else and starts the app.

      1 Download the setup file

      2 Run it: python setup_brain_mri_triage.py

      It checks every file against its checksum, installs what it needs and opens this page on your machine. About 1.7 GB. After that it never touches the internet again.

      The individual files, and doing it by hand

      The setup file above does all of this for you. To do it manually: put the .pth files in a models folder next to the app, put deployment_config.json in analysis/results/safety/ and rejector_config.json in analysis/results/ood/, then run python -m app.

      Check a file on Windows with certutil -hashfile best_vit_seed42.pth SHA256. A part-downloaded model can still load and then give wrong answers.
