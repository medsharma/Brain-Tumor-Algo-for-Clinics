    Run this yourself, offline

    These are the exact files this server is running on. Downloaded and put next to a copy of the app, they give the same answers this page gives. Not a similar model. The same weights and the same safety settings.

    Once installed it needs no internet at all. That is the point: a clinic with no radiologist and no reliable connection can run it on a laptop.

    How to use these files
    1. Download every file in the table. All of them are needed.
    2. Check each SHA-256 against the value shown. A part-downloaded model file can still load and then give wrong answers.
    3. Put the .pth model files in a models folder next to the app.
    4. Put the two .json settings files where the app expects them, as described in the app's README.
    5. Start the app. It refuses to start if anything is missing or does not match, which is deliberate.

    On Windows you can check a file with: certutil -hashfile best_vit_seed42.pth SHA256
